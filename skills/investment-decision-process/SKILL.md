# Investment Decision Process

Decisions get made once and reviewed forever. Structure every position: thesis → evidence → valuation → sizing → monitoring → exit — documented before money moves. (Process discipline, not financial advice; the decision-maker owns the call.)

## When to use
- Any new position, add, trim, or exit decision.
- Periodic portfolio reviews; post-loss reviews.
- Any "this looks good" impulse — that's what this skill is for.

## Method
1. **Thesis first (falsifiable)**: why this asset, why now, what must be true; name the edge (informational / analytical / structural / behavioral). "It's going up" is not a thesis.
2. **Evidence standards**: primary sources (filings, data with provenance); separate facts / estimates / opinions; actively collect disconfirming evidence (`behavioral-finance`).
3. **Valuation & price check**: entry range with margin of safety (`valuation-methods`); what you're paying vs what you get.
4. **Sizing & risk before entry**: max loss per position pre-defined; fits portfolio rules (`risk-management`, `portfolio-construction`).
5. **Pre-mortem + kill criteria**: what would make this fail; what would falsify the thesis — write it before entry.
6. **Decision journal**: date, thesis summary, evidence links, valuation, sizing, exit plan; revisit on schedule; log outcomes + lessons.
7. **Monitoring**: define update triggers (data, events) and a review cadence; exit on thesis break or better opportunity — documented, not vibes.
8. **House gates**: trades >$500 need explicit confirmation; cooling-off for impulsive ideas; no entry without a journal note.

## Quality gates
- [ ] Written thesis + kill criteria before entry.
- [ ] Evidence sources recorded; disconfirming evidence section present.
- [ ] Sizing within portfolio rules; max loss known.
- [ ] Journal entry complete; review dates set.

## Red lines
- No trade without thesis; no averaging down without re-underwriting; never leak positions/account data (`privacy-compliance` — financials are private period).
