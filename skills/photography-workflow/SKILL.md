# Photography Workflow

Commercial shoots (interior, architectural, product, food) are production pipelines: rights defined before, backups during, specs honored after. This skill runs the full cycle without the classic failures.

## When to use
- Planning, shooting, or delivering a commercial photography engagement.
- Setting up repeatable studio/on-location workflows and archives.
- Improving a photography business's client experience or licensing hygiene.

## Method
1. **Brief & pre-production**: usage rights (media, term, territory), deliverables list, locations/permits/scheduling, shot list + moodboard, styling/staging needs; interior/arch: access, angles, decluttering; product/food: surfaces, props, freshness.
2. **Capture**: tethered where practical; calibrated profiles; on-set backup with 3-2-1 discipline and verification; IPTC metadata template (creator, copyright, capture info) applied on import.
3. **Culling & edit**: selects → consistent grade across the set; retouch policy per usage (dust/reflection cleanup vs full comp); RAWs preserved untouched.
4. **Client proofing**: watermarked review galleries, defined revision rounds, approvals captured in writing; versioned exports.
5. **Delivery**: format/size/color per spec (sRGB web vs AdobeRGB print), correct crops per usage; transfer by download link or drive — never email finals.
6. **Licensing & billing**: scope in writing before the shoot; invoice states license terms; credit requirements; contracts and releases on file (see legal-licensing).
7. **Archive**: catalog by client/date/shoot ID, checksums, offsite copy; retention and deletion policy; portfolio use only within license/agreement.

## Quality gates
- [ ] Rights + deliverables defined in writing before capture.
- [ ] Backups verified on set; originals preserved.
- [ ] Delivery specs (format, color, size) met; transfer method tracked.
- [ ] License terms on the invoice; releases archived.
- [ ] Catalog searchable; portfolio use permitted by agreement.

## Red lines
- Never deliver without agreed terms; never use images beyond license (including self-promotion) without permission.
- Client RAWs stay private unless the agreement says otherwise; minors/private spaces handled with consent.
- No "we'll fix it in post" on set for things post cannot fix (access, light, scheduling).
